Interpreter settings

Translating your input into game commands calls an LLM API directly from your browser using your own API key. The key is stored only in this browser's local storage and is sent only to the provider you choose below.

Anthropic and OpenAI reliably accept these direct browser calls. Gemini's API does too in most setups, but Google's CORS support for it is less consistently documented — if it errors out for you, raw mode is always available as a fallback.
